# Writter：从文字生成到文章编辑

## 本轮判断

用户要的是可读、有主线、结构能讲清楚的公众号成品。旧流程能够生成文字，却没有把这些要求落实到策划、生成和审稿中。现有成品不足以证明模型能力差是唯一原因；更换模型之前，应使用一致材料与要求比较实际文章。

目前只冻结主要工作流，不冻结文章模板。不能把所有文章都套成三段并列材料，也不能将这份新闻验收样例当成用户公众号的最终风格。

## 已改动

| 环节 | 编辑目标 | 实现 |
| --- | --- | --- |
| 策划 | 说明给谁看、回答什么、中心判断与阅读收获 | 模型输出有结构的策划，转换为现有可编辑的 angle/outline 字符串，保留保存、历史与确认快照兼容性 |
| 段落组织 | 各部分有作用、关键内容、依据、承接 | 在大纲中展示这些信息，不新增需要用户手工填写的表单 |
| 用户调整 | 不能只替换标题、保留原来的材料拼接 | 重新组织问题、论点与材料；不支持的角度应解释缺口并给出有依据的替代策划 |
| 正文 | 开篇提出具体问题、展开有信息推进、结尾回应 | 生成使用确认后的完整策划；防止宽泛升华、目标变成果、合作变自主创新 |
| 文字修改 | 用户用自然语言指出希望怎么改 | 现有 draft 任务接受修改意见，带入当前正文与复查结果；修改后复查及预览过期 |
| 复查 | 事实正确不等于结构好、文字好 | 三个维度单独给结论；问题必须定位并附可执行建议，严重的主线或证据问题阻止发布 |
| 使用反馈 | 判断实际成品，不把模型自评当最终验收 | UI 展示各维度发现及改法；旧复查标明缺少结构与文字评价 |

这些约束是编辑要求，程序验证只保证字段、引用定位与状态一致性。没有实现可确定性证明的语义蕴含检查；模型仍可能漏检或误判，因此必须读实际文章。

## 已完成的验证及边界

- 37 项测试、语法检查及构建通过。覆盖富策划、定位/结论一致性、结构问题阻止预览、修改意见持久化和修改后审稿失效。
- 前端使用 happy-dom 和模拟云调用，没有进行新版真实浏览器视觉验收。
- 人工成品复盘与参考改稿见 [editorial-quality-reference.md](artifacts/editorial-quality-reference.md)。它是助手编辑对照，不是新版模型生成。
- 当前运行环境没有 WRITTER_AI_KEY，且没有 CloudBase 部署能力；本轮未调用真实模型，未部署，也没有修改云端模型或其他环境变量。
- 历史任务与复查保持兼容；旧复查未额外证明结构和文字质量，需要重新审稿。原有旧预览不会因为代码更新而自动被撤回。

## 下一次真实成品验收

1. 使用同一个选题、同一份资料与同一组修改要求运行实际工作流，保存策划、修改后策划、正文和审稿。至少包括真实 AI/产品热点，不能只用这份综合新闻样例代表全部题材。
2. 先读正文，再看模型自评。检查能否用一句话概括全文问题与结论；能否解释各部分的作用；中间段落有没有重复和逻辑跳跃；结尾是否回答开篇。
3. 对照来源检查目标/成果、投入/效果、合作/自主创新等区别；故意要求没有证据的角度，观察模型如何解释缺口和提供替代方案。
4. 提出一条局部文字修改，观察有没有保留其他内容、事实和主线。重新审稿后再预览。
5. 比较模型时使用完全相同材料与要求。不能根据某一次成功 JSON 或模型自评宣布质量通过。记录失败、延迟和实际文章；如单次差异不明确，再补样例，不预设高级模型一定更好。

已提供 `npm run eval:editorial`，使用安全环境中已有的模型配置执行四次调用（检测、调整、生成、审稿）。默认只测试实际配置模型；需要比较时明确设置 `WRITTER_AI_EVAL_MODELS` 为模型名列表，最多三个，不自动升级或切换生产模型。结果保存在忽略提交的 `artifacts/editorial-eval/`，含固定摘录、实际提示词和输出，不含密钥。该脚本验证编辑任务而非云端登录、数据库或联网来源读取，结果仍需人工评价。

## 后续排版承接

先确定文章的语义结构，再实现标题、正文、完整强调句、引用与说明块的视觉映射。AI 不生成 CSS；保留绿色、米色、克制留白和内缩卡片的方向，不堆组件、不添加莫名横线。真机背景、卡片、亮暗模式及复制后显示优先验收。当前 renderer 仍是基础版，不能标记为精确 V25 或最终公众号排版。

## 部署说明

更新需要同时发布云函数代码与 hosting 前端，因为模型输出契约和界面一起变更。使用 `tcb fn code update` 等仅更新代码方式；不要用本轮代码修改作为覆盖环境变量的理由。密钥继续仅留云端。保留生产 WRITTER_AI_MODEL 配置，实际模型以云端变量为准；未完成成品比较前不宣称应换某个模型。
