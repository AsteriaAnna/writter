# GREEN / 01

墨绿 × 荧光绿 × 米白的微信公众号组件库。当前为 v0.2 兼容性修订版，**微信手机端仍待验收**。

- [组件代码与使用规则](references/components.md)：21 个基础组件，含正文展示标题、一级章节标题、二级小节标题、正文、图片、问答和代码块。
- [完整预览与富文本复制](examples/preview.html)：下载仓库后，用浏览器打开此文件，点击“复制正文到公众号”。GitHub 文件页面只展示源代码，不会渲染预览。
- [纯正文 HTML](examples/article.html)：只包含需要粘贴的正文，无预览工具栏、脚本和文档外壳。

## 使用

1. 下载仓库 ZIP 并解压，浏览器打开 `examples/preview.html`。
2. 这是全部组件的测试合集；正式文章按需选用，不要全部照搬。示例图片来自微信结构规范公开演示，使用自己的文章时先替换为自己上传的图片，保留正确的原始宽度。
3. 先点“复制纯文字基线”，测试最简单的文字能否显示（纯正文文件为 `examples/baseline.html`），再点“复制全部组件到公众号”。浏览器阻止自动复制时按页面提示手动复制已选正文；不要复制 HTML 源码或 Markdown 围栏。全部组件中的图片必须加载成功，否则页面会提示换图；纯文字基线不依赖图片。
4. 保存草稿、重新打开、发送手机预览，并检查浅色和深色模式。网页预览与本地校验不等于微信验证通过。

## 更新组件后重新生成

```bash
python scripts/build_preview.py
python scripts/check_html.py examples/article.html
```

Python 3 标准库即可，无需安装第三方依赖。组件文档是来源，examples 为生成物。预览中的 JS 只用于复制，不属于公众号正文。
